# 고3 담임 업무 도우미 · 7차 개발

고3 담임 선생님이 **달마다 챙길 업무**를 보고 체크하는 웹사이트입니다.
기본 자료는 **2027학년도 고3 · 2028학년도 대입** 기준입니다(시트 `설정` 탭의 학년도·대입 학년도. 모든 화면 머리에 표시).

- 사이트: https://sewoongyun.github.io/hr-helper/ (2026-11-09 현재 6차가 배포 중. 7차는 로컬 검증까지 마친 상태)
- 7차를 실제로 적용하는 방법: **[적용_순서.md](적용_순서.md)**
- 7차에서 고친 점: 아래 [7차에서 바뀐 점](#7차에서-바뀐-점-2026-11-09-코드-검토-반영)

## 7차에서 바뀐 점 (2026-11-09 코드 검토 반영)

| # | 문제(6차에서 재현 확인) | 고친 내용 |
|---|---|---|
| 1 | 학번 때문에 막은 질문이 대화 기록에 남아 **다음 질문 때 서버·AI로 전송**됨 | 화면 대화와 AI 전송용 기록을 분리. 막은 질문과 그 답은 전송용 기록에 넣지 않음. 서버도 질문과 이전 대화를 다시 검사해, 개인정보로 보이는 질문은 처리하지 않고 그런 이전 대화 줄은 빼고 보냄. 메일 주소·`몇 반 몇 번`도 막음. 안내 문구를 "숫자 모양만 걸러지고 이름은 걸러지지 않음"으로 바로잡음 |
| 2 | 자료 자동 정리가 체크 저장과 같은 잠금을 잡은 채 AI를 기다려 **정리 중 체크 저장이 실패**할 수 있음 | 느린 변환·AI 호출을 공용 잠금 밖으로 뺌. 짧은 잠금 안에서 '정리 실행권'(누가, 언제까지)만 기록. 중복 실행 방지, 실행이 멈춰도 만료 시각이 지나면 다시 정리, 끝나거나 오류가 나면 바로 실행권을 풂 |
| 3 | 429·통신 오류도 '실패'로 굳어 **원본이 그대로면 다시 시도하지 않음** | 오류를 일시(429·5xx·통신)·설정(키·모델)·형식(한글 파일 등)으로 구분. 일시 오류는 요청 안에서 2번(2초·4초) 다시 보내고, 그래도 안 되면 5→10→20→40분 뒤 다음 실행에서 이어서 최대 4번. 키·모델을 바꾸면 자동으로 다시 시도. 다람이 창에 **실패 자료 다시 시도** 단추 |
| 4 | 캐시에 글자 수(9만 자)로 넣어 **한글 4만 자 문서(12만 바이트)는 오류**가 나고 검색에서 빠짐 | UTF-8 바이트로 재서 9만 바이트씩 나눠 저장. 캐시에 못 넣어도 읽은 글은 그대로 검색에 씀 |
| 5 | 하루 한도가 채팅에만 있고, 키가 '있기만 해도' "AI 정리 켜짐"으로 표시 | 하루 요청 횟수를 다람이 질문(`CHAT_DAILY_LIMIT`)과 자료 정리(`DIGEST_DAILY_LIMIT`, 재시도 포함)로 나눠 세고 표시. **요청 횟수 제한이며 비용 상한이 아님**을 화면에 밝힘. "AI 키 설정됨 · 연결 확인 전"과 "AI 연결 확인됨 · 마지막 성공 시각"을 구분. **AI 연결 시험**(누를 때만 짧은 요청 1번)으로 인증 오류·모델 오류·한도 초과·정상 응답을 구분. 키는 계속 스크립트 속성에만 두고 브라우저로 돌려주지 않음 |
| 6 | 자료의 적용 범위·근거가 한눈에 보이지 않음 | 모든 화면 머리에 "2027학년도 고3 · 2028학년도 대입 기준". 권장과목 카드에 근거 한 줄(적용 학년도·전형·출처 URL·원문 위치·확인일·검증 상태). 모르는 값은 **미확인**, 검증 전 자료는 **검증 대기**로 두고 '검증 완료'는 시트에 직접 적었을 때만 보임. 시트 `권장과목` 탭에 근거 칸 6개를 뒤에 추가(칸이 없는 기존 탭도 그대로 동작). 다람이 근거 카드에서 원문과 **AI 정리본**·변환본을 나눠 표시하고 정리본이면 원문 링크도 함께 |
| + | 다람이 창을 열면 머리 아이콘의 흰 몸·얼굴이 사라짐 | 한 화면에 같은 그림이 두 번 들어가 색 정의(id)가 겹쳤고, 창을 열 때 숨는 단추 쪽 정의를 쓰고 있었음. 그림마다 id를 따로 줌. 아이콘을 키우고 어두운 화면 바탕도 맞춤 |
| + | 생각 수준 | 단순한 질문은 빠르게(low), 비교·조건·여러 자료를 엮는 질문과 이어지는 대화는 꼼꼼히(medium). `GEMINI_THINKING` 속성으로 고정 가능 |

기존 기능·업무 ID·시트 구조·체크 기록 형식은 그대로입니다. 디자인은 6차를 유지하고 상태 표시와 단추만 더했습니다.

## 다람이와 AI

| 단계 | 필요한 것 | 답하는 방식 | 찾는 자료 |
|---|---|---|---|
| 검색 | 없음 | 찾은 자료를 카드로 | 업무·일정·자료실·권장과목 |
| 검색 + 폴더 | 학년 코드로 시트 연결 | 같음 | 위 + 교직이수 + 드라이브 `고3 담임 도우미 챗봇 자료` 폴더 |
| AI 정리 | 위 + 스크립트 속성에 AI 키 | 찾은 자료만 근거로 문장 답, [1] [2] 근거 번호와 출처 카드 | 같음 |

**개인정보 — 정확히 무엇이 막히나**
- 다람이는 질문에 **숫자 모양의 개인정보**(5자리 이상 숫자=학번 등, 전화번호, 주민등록번호, `몇 반 몇 번`)나 **메일 주소**가 있으면 서버·AI로 보내지 않고, 그 질문은 다음 대화에도 함께 보내지 않습니다. 서버에서도 한 번 더 검사합니다.
- **학생 이름은 자동으로 걸러지지 않습니다.** 질문에 이름을 적지 않도록 안내해 주세요.
- 자료 정리에서 PDF·사진은 **파일 전체가 AI 회사로 전송**됩니다. AI에게 "개인정보를 옮기지 말라"고 지시하지만 이는 정리본에 적지 말라는 뜻일 뿐 **전송을 막지 못합니다**. 보내면 안 되는 파일은 폴더에 넣지 말거나 이름 앞에 `[AI 제외]`를 붙이세요(AI로 보내지 않음).
- 무료 Gemini는 Google 가격 안내에 무료 등급 입력이 "제품 개선에 쓰인다"고 적혀 있습니다(2026-11-09 확인).

**자료 폴더 자동 정리**

| 넣은 파일 | 처리 | AI 키 |
|---|---|---|
| 구글 문서, .txt, .md | 그대로 읽음 | 필요 없음 |
| 워드·엑셀·파워포인트, 구글 시트·슬라이드 | 구글 변환으로 글자를 뽑음(변환본). 키가 있으면 AI 요약을 붙임 | 없어도 됨 |
| PDF(그림만 있는 PDF 포함), 사진 | AI가 읽고 정리(AI 정리본) | 필요 |
| 한글(.hwp) | 못 읽음 → PDF로 저장해 넣기 | - |

- 정리본은 폴더 안 `자동 정리(다람이)`에 쌓이고, 맨 위에 원본 링크가 있습니다. 1시간마다 자동(처음 한 번 `setupAutoDigest` 실행) 또는 다람이 창 **자료 정리**에서 바로 돌립니다.
- 한 파일 14MB까지. 100쪽이 넘는 PDF는 30쪽 안팎으로 나눠 넣으면 안전합니다.

**설정(스크립트 속성)** — 이름과 기본값은 `Code.gs` 맨 위 설명에 모두 있습니다.
`GEMINI_API_KEY`/`ANTHROPIC_API_KEY`, `AI_PROVIDER`, `GEMINI_MODEL`(기본 `gemini-3.8-flash`: Google AI Studio 가격 안내의 무료 등급 모델 목록에서 2026-11-09 확인), `CLAUDE_MODEL`(기본 `claude-opus-5-5`), `GEMINI_THINKING`, `CHAT_DAILY_LIMIT`(200), `DIGEST_DAILY_LIMIT`(60), `CHAT_FOLDER_ID`.
키 만드는 방법은 [적용_순서.md](적용_순서.md)에 있습니다.

## 시트 고치는 법

| 탭 | 내용 |
|---|---|
| `설정` | 학년도, 대입 학년도, 학교, 반 목록, 학년 코드 |
| `월별 요약` | 달마다 제목과 핵심 한 줄 |
| `업무` | 한 줄이 업무 하나. **월**은 `준비`, `3`~`12`, `1`, `2`, `매월`. **자료**에는 `자료` 탭의 ID를 쉼표로. **ID는 한 번 정하면 바꾸지 마세요**(체크 기록이 ID로 연결됨) |
| `일정` | ID, 시작일·종료일, 시각(마감 시각), 일정, 구분, 중요, 비고 |
| `자료` | 링크와 공개 범위(`공개`/`교사용`) |
| `진행` | 사이트에서 체크하면 쌓임. 머리글(반, 업무 키, 완료, 메모, 수정 시각)은 바꾸지 마세요 |
| `폼 요약` | 이름, 반, 응답 시트 주소, 탭 이름, 날짜 열 키워드, 중복 확인 열 키워드, 대상 인원 |
| `권장과목` | 권장과목 화면의 「시트로 보내기」로 처음 만들어짐. 7차 근거 칸: `적용 학년도`, `전형`, `출처 URL`, `원문 쪽수`, `확인일`, `검증 상태` (기존 탭에는 맨 뒤에 머리글만 추가하면 됨. 없어도 동작) |
