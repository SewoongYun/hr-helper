# 7차 적용 순서

7차 사이트는 2026-11-09에 GitHub Pages로 배포했습니다(4번 완료). **Apps Script(1~2번)는 선생님이 직접 적용해야 합니다.**
아래 순서대로 적용하세요. 서버(Apps Script)를 먼저 바꾸고 사이트를 나중에 바꿉니다.
6차 사이트는 7차 서버와도 그대로 동작하므로, 1~3단계를 마친 뒤 4단계 전까지 잠깐 섞여 있어도 괜찮습니다.

## 1. Apps Script 코드 바꾸기 (5분)

1. 구글 시트 → **확장 프로그램 → Apps Script**
2. 왼쪽 `Code.gs`를 누르고 내용을 **Ctrl+A → Delete**로 모두 지웁니다.
3. 내 컴퓨터의 `7차_개발\apps-script\Code.gs`를 메모장으로 열어 **전체 복사 → 붙여넣기 → Ctrl+S**
4. 위쪽 함수 고르기에서 **`setupAutoDigest`** → **▶ 실행**
   - 권한 창이 뜨면 **권한 검토 → 계정 선택 → 고급 → 이동 → 허용**. (이미 승인한 권한이면 창이 뜨지 않습니다)
   - 실행 로그에 오류가 없으면 됩니다. 1시간마다 자동 정리 트리거는 이미 있으면 그대로 둡니다.
5. (AI 키가 있으면) 함수 고르기에서 **`testAiConnection`** → **▶ 실행** → 아래 **실행 로그**에서 결과 확인
   - `"result":"ok"` → 정상 연결
   - `"auth"` 인증 오류(키 확인) / `"model"` 모델 오류(`GEMINI_MODEL` 확인) / `"quota"` 한도 초과(잠시 뒤 다시) / `"nokey"` 키 없음
   - 이 시험은 실행할 때만 아주 짧은 요청 1번을 보냅니다.

## 2. 새 버전으로 배포 (1분)

**배포 → 배포 관리 → 연필(편집) → 버전: 새 버전 → 배포**
- '새 배포'가 아니라 기존 배포를 **편집**해야 주소가 그대로입니다.
- 설정은 그대로: 실행 = 나, 액세스 = 모든 사용자

## 3. (선택) 시트 `권장과목` 탭에 근거 칸 추가

`권장과목` 탭이 이미 있으면 맨 오른쪽 빈 칸들 첫 줄에 머리글 6개를 적습니다.
`적용 학년도` · `전형` · `출처 URL` · `원문 쪽수` · `확인일` · `검증 상태`
- 아직 탭이 없으면 할 일이 없습니다(사이트의 「시트로 보내기」가 칸까지 만들어 줍니다).
- 칸을 만들지 않아도 사이트는 정상 동작하고, 근거는 '미확인'으로 보입니다.
- '검증 완료'는 원문과 대조를 끝낸 줄에만 직접 적어 주세요.

## 4. 사이트(GitHub Pages)를 7차로 바꾸기

1. `.github/workflows/deploy-pages.yml`의 `SITE_DIR`을 `"7차_개발/site"`로 바꿉니다.
2. 상위 `README.md` 표에서 7차를 '지금 배포 중', 6차를 '보관용'으로 바꿉니다.
3. 커밋하고 푸시합니다.
   ```bash
   git add .
   git commit -m "7차 배포: SITE_DIR 변경"
   git push
   ```
4. GitHub의 Actions에서 'Deploy site'가 끝나면(1분 안팎) 사이트를 **Ctrl+F5**로 새로고침합니다.
   - 7차 사이트 파일 캐시 번호는 `?v=13`입니다.

## 5. 적용 뒤 실제 환경에서 확인할 것

로컬 테스트는 모의 환경이라, 아래는 실제 Google 환경에서만 확인할 수 있습니다.

| 확인 | 방법 | 기대 결과 |
|---|---|---|
| 서버가 7차인지 | 학년 코드 입력 → 다람이 → **자료 정리** | '할 차례·다시 시도 대기·실패' 숫자와 '오늘 AI 요청' 줄이 보임 |
| AI 실제 연결 | 같은 창 **AI 연결 시험** | "정상 응답을 받았습니다" → 다람이 머리에 "AI 연결 확인됨 · 마지막 성공 …" |
| 개인정보 차단 | "학생 30123 상담" → 이어서 "9월 할 일" | 첫 질문은 사이트 자료만, 둘째 질문은 정상 답 |
| 정리 중 체크 저장 | 자료 폴더에 작은 PDF를 넣고 **지금 정리하기**를 누른 직후 다른 창에서 업무 체크 | 체크가 바로 저장됨 |
| 실패 자료 다시 시도 | 자료 정리 창의 단추 | 실패·대기 자료를 다시 정리 |
| 큰 한글 문서 | 폴더에 긴 구글 문서(수만 자)를 넣고 그 안의 낱말로 질문 | 그 문서 문단이 근거로 나옴 |
| 다람이 아이콘 | 다람이 창 열기(밝은·어두운 화면) | 머리 아이콘에 흰 로봇 몸과 얼굴이 보임 |
| Gemini 생각 수준 설정 | 비교 질문("부산대 경북대 수학교육과 차이") | 답이 옴(모델이 설정을 모르면 서버가 설정을 빼고 다시 보냄) |

문제가 있으면 다람이 창이나 Apps Script **실행** 기록의 오류 메시지를 캡처해 주세요.
