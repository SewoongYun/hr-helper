# 9차 적용 순서

9차 사이트는 2026-11-10에 GitHub Pages로 배포했습니다(4번 완료). **Apps Script(1~3번)는 선생님이 직접 적용해야 합니다.**
9차 서버에 8차 사이트를 붙여도 동작합니다(자료 정리는 서버 일이라 1~3번만 해도 드라이브 원문 검색은 바로 좋아집니다).

## 1. Apps Script 코드 바꾸기 (5분)

1. 구글 시트 → **확장 프로그램 → Apps Script**
2. 왼쪽 `Code.gs`를 누르고 내용을 **Ctrl+A → Delete**로 모두 지웁니다.
3. 내 컴퓨터의 `9차_개발\apps-script\Code.gs`를 메모장으로 열어 **전체 복사 → 붙여넣기 → Ctrl+S**
   - 맨 위 주석에 `· 9차`가 보이면 맞습니다.

새 권한은 필요 없습니다(8차와 같은 서비스만 씀).

## 2. 새 버전으로 배포 (1분)

**배포 → 배포 관리 → 연필(편집) → 버전: 새 버전 → 배포**
- '새 배포'가 아니라 기존 배포를 **편집**해야 주소가 그대로입니다.
- 설정은 그대로: 실행 = 나, 액세스 = 모든 사용자

## 3. PDF를 새 방식으로 다시 정리 (자동, 서두르려면 직접)

코드를 바꾸면 지금까지 AI 요약으로 만든 PDF 정리본 3개와 정리되지 않던 119 자료집(15.5MB)이 모두 '할 차례'가 됩니다.

- **그냥 두면** 1시간마다 도는 자동 정리가 한 번에 4분씩 처리합니다.
- **바로 하려면** 편집기 위쪽 함수 고르기에서 **`autoDigest`** → **▶ 실행**(한 번에 4분). 아래 **실행 로그**가 끝나면 한 번 더 실행해 남은 파일을 마저 정리합니다.
  - 또는 사이트 다람이 창 → **자료 정리** → **지금 정리하기**(한 번에 1분 남짓, 여러 번 눌러야 할 수 있음)

**정리 결과에서 볼 것** (다람이 창 '자료 정리' → '지금 정리하기' 결과 줄)

| 줄 모양 | 뜻 |
|---|---|
| ✓ 파일 · 구글 변환으로 원문 글자를 뽑음 + AI 요약 · 185,000자 | 정상. 원문 전체가 검색됨 |
| ✓ 파일 · Gemini가 파일을 직접 읽고 정리함 · 7,000자 | 구글 변환이 안 되어 AI 요약으로 대신함(세부 내용은 빠짐) |
| △ 파일 · 원문 글자는 저장해 검색됩니다. AI 요약만 다시 시도합니다 | AI가 잠깐 안 됨. 검색은 이미 되고 요약은 자동으로 다시 시도 |
| ✗ 파일 · PDF(…): 파일이 커서(14MB 넘음) AI로도 한 번에 읽지 못합니다 | 구글 변환도 안 되고 AI로도 못 읽음 → 파일을 나눠 넣기 |

- **글자 수를 꼭 보세요.** 쪽수에 비해 너무 적으면(예: 300쪽인데 몇천~1만 자) 변환이 중간에 끊긴 것입니다. 그 파일은 100쪽 안팎으로 나눠 넣어 주세요.
- 드라이브 `자동 정리(다람이)` 폴더의 정리본을 열어 「■ 원문 글자」 아래에 본문이 끝까지 들어 있는지 눈으로 확인할 수도 있습니다.

## 4. 사이트(GitHub Pages)를 9차로 바꾸기

1. `.github/workflows/deploy-pages.yml`의 `SITE_DIR`을 `"9차_개발/site"`로 바꿉니다.
2. 상위 `README.md` 표에서 9차를 '지금 배포 중', 8차를 '보관용'으로 바꿉니다.
3. 커밋하고 푸시하면 1분 안팎에 배포됩니다. 사이트를 **Ctrl+F5**로 새로고침합니다(캐시 번호 `?v=15`).

## 5. 적용 뒤 실제 환경에서 확인할 것

로컬 테스트는 모의 환경이라, 아래는 실제 Google 환경에서만 확인할 수 있습니다.

| 확인 | 방법 | 기대 결과 |
|---|---|---|
| PDF가 구글 변환으로 정리되는지 | 3번의 결과 줄 | '구글 변환으로 원문 글자를 뽑음'과 분량에 맞는 글자 수 |
| 15.5MB 119 자료집 | 같은 곳 | 변환되면 ✓와 글자 수. 안 되면 ✗와 까닭 → 나눠 넣기 |
| 세부 내용 검색 | 다람이에게 자료집 안의 구체적인 내용(예: 대학 이름 + 학과 + 권장과목) | 근거 카드에 '원문 변환' 표시와 그 줄이 보임 |
| 바로 답 + 드라이브 | "수시 원서 접수 일정" | 바로 답이 먼저 나오고, 몇 초 뒤 아래에 '드라이브 자료에서 찾은 내용'이 접힌 채 붙음 |
| 검색 속도 | 답 아래 시간 줄의 '자료 찾기' | 원문이 늘어난 만큼 조금 늘 수 있음. 5초를 넘으면 알려 주세요 |
