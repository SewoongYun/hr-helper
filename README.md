# 고3 담임 업무 도우미

고3 담임 선생님이 달마다 챙길 업무를 보고 체크하는 웹사이트입니다. 버전마다 폴더를 따로 두었습니다.

사이트 주소: https://sewoongyun.github.io/hr-helper/

| 폴더 | 내용 | 배포 |
|---|---|---|
| [6차_개발](6차_개발/README.md) | 5차 + 자료 폴더 자동 정리(PDF·사진은 AI가 읽고, 워드·엑셀·파워포인트·시트는 구글 변환), 다람이 '자료 정리' 단추, 그라데이션·유리 느낌 디자인 개편, API 키 단계별 안내 | **지금 배포 중** |
| [5차_개발](5차_개발/README.md) | 4차 + 자료 도우미 챗봇 '다람이'(사이트 자료·드라이브 '챗봇 자료' 폴더 검색, AI 키를 넣으면 근거 번호를 단 문장 답변 · Gemini 또는 Claude) | 보관용 |
| [4차_개발](4차_개발/README.md) | 3차 + 핵심자료 반영(권장과목을 권역별 엑셀 47개 대학 1,358줄로 다시 만들고 3차와 대조, 반영과목 판정 규칙 보강, 교직이수 개설 학과 검색(교사용), 지역의사제 업무) | 보관용 |
| [3차_개발](3차_개발/README.md) | 2차 + 소스 검토 20개 항목 반영(하반기 모평 8월, 권장과목 판정 범위 표시, 변환 고지, 저장 공간 분리·업로드 확인, 동시 수정 보호, 코드 차단 개선, 폼 집계 기준, 접근성) | 보관용 |
| [2차_개발](2차_개발/README.md) | 월별 업무 + 내신 9↔5 변환, 대학별 권장과목 확인, 디자인 개편, 화면 폭별 메뉴(세로 탭, 휴대폰 아래 탭 바) | 보관용(검토 원본) |
| [1차_개발](1차_개발/README.md) | 첫 버전: 월별 업무 88개, 연간 흐름, 학년 현황, 자료실, 폼 요약, 구글 시트 연동 | 보관용 |

```
고3 담임 업무 도우미/
├─ 1차_개발/            첫 버전 (보관)
│  ├─ site/
│  ├─ apps-script/Code.gs
│  └─ README.md
├─ 2차_개발/            두 번째 버전 (보관, 소스 검토 원본)
├─ 3차_개발/            세 번째 버전 (보관)
├─ 4차_개발/            네 번째 버전 (보관)
├─ 5차_개발/            다섯 번째 버전 (보관)
├─ 6차_개발/            지금 쓰는 버전
│  ├─ site/            ← GitHub Pages로 배포되는 폴더
│  ├─ apps-script/Code.gs
│  ├─ 검토/            권장과목 대조 결과
│  └─ README.md        사용법, 시트 연결, 배포 방법
├─ 핵심자료들/          원본 자료 (저장소에 올리지 않음)
│                       (챗봇 자료는 구글 드라이브 '고3 담임 도우미 챗봇 자료' 폴더에 둡니다)
├─ .github/workflows/deploy-pages.yml   배포할 폴더(SITE_DIR)를 정하는 파일
└─ README.md           (이 파일)
```

## 새 버전을 만들 때

1. 지금 버전 폴더를 통째로 복사해 `7차_개발`처럼 새 이름을 붙입니다.
2. 새 폴더에서 고칩니다. 이전 폴더는 그대로 둡니다.
3. `.github/workflows/deploy-pages.yml`의 `SITE_DIR`을 `"7차_개발/site"`처럼 새 폴더로 바꿉니다.
4. 위 표에 한 줄 추가하고 커밋, 푸시합니다.

구글 시트와 Apps Script는 버전과 관계없이 하나를 같이 씁니다. 새 버전에서 `Code.gs`를 바꿨다면 Apps Script에 다시 붙여 넣고 새 버전으로 배포하세요.
