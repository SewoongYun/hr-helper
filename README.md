## 새 버전을 만들 때

1. 지금 버전 폴더를 통째로 복사해 `11차_개발`처럼 새 이름을 붙입니다.
2. 새 폴더에서 고칩니다. 이전 폴더는 그대로 둡니다.
3. `.github/workflows/deploy-pages.yml`의 `SITE_DIR`을 `"11차_개발/site"`처럼 새 폴더로 바꿉니다.
4. 위 표에 한 줄 추가하고 커밋, 푸시합니다.

구글 시트와 Apps Script는 버전과 관계없이 하나를 같이 씁니다. 새 버전에서 `Code.gs`를 바꿨다면 Apps Script에 다시 붙여 넣고 새 버전으로 배포하세요.
