# 8차 적용 순서

8차 사이트는 GitHub Pages로 배포합니다(4번). **Apps Script(1~2번)는 선생님이 직접 적용해야 합니다.**
7차 서버에 8차 사이트를 붙여도 동작하지만(간단한 질문은 바로 답함), 시간 기록·재시도 0·근거 8개 제한은 8차 서버를 붙여야 적용됩니다.

## 1. Apps Script 코드 바꾸기 (5분)

1. 구글 시트 → **확장 프로그램 → Apps Script**
2. 왼쪽 `Code.gs`를 누르고 내용을 **Ctrl+A → Delete**로 모두 지웁니다.
3. 내 컴퓨터의 `8차_개발\apps-script\Code.gs`를 메모장으로 열어 **전체 복사 → 붙여넣기 → Ctrl+S**
   - 맨 위 주석에 `· 8차`가 보이면 맞습니다.
4. (선택) 함수 고르기에서 **`testAiConnection`** → **▶ 실행** → 실행 로그에 `"result":"ok"`가 보이면 정상

새 권한은 필요 없습니다(7차와 같은 서비스만 씀).

## 2. 새 버전으로 배포 (1분)

**배포 → 배포 관리 → 연필(편집) → 버전: 새 버전 → 배포**
- '새 배포'가 아니라 기존 배포를 **편집**해야 주소가 그대로입니다.
- 설정은 그대로: 실행 = 나, 액세스 = 모든 사용자

## 3. 사이트(GitHub Pages)를 8차로 바꾸기

1. `.github/workflows/deploy-pages.yml`의 `SITE_DIR`을 `"8차_개발/site"`로 바꿉니다.
2. 커밋하고 푸시하면 1분 안팎에 배포됩니다. 사이트를 **Ctrl+F5**로 새로고침합니다(캐시 번호 `?v=14`).

## 4. 걸린 시간 확인하는 법

- **다람이 답 아래**: `자료 찾기 0.4초 · AI 6.1초 · 서버 전체 6.8초 · 화면까지 8.2초`
  - '화면까지'가 '서버 전체'보다 많이 길면 Apps Script 웹 앱 자체의 시작·전달 시간입니다.
- **Apps Script 실행 기록**: 왼쪽 **실행**(▶ 모양 목록) → `doPost` 줄을 누르면 `[다람이 시간] {"ai":true,"result":"ok","level":"low","sources":8,"promptChars":…,"searchMs":…,"aiMs":…,"totalMs":…}`
  - `result`가 `ok`가 아니면 `quota`(한도) / `server`(AI 회사 서버) / `network` / `auth`(키) / `model`(모델 이름) 중 하나입니다.
  - 질문 글·학생 정보·키는 기록하지 않습니다.
