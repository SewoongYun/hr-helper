# 11차 적용 순서

11차 사이트는 2026-11-12에 GitHub Pages로 배포했습니다(5번 완료). 로컬 회귀 테스트는 48개 통과했습니다. 10차 서버를 아직 적용하지 않았어도 됩니다. **11차 Code.gs에 10차 수정(자료 정리 끊김)이 모두 들어 있으니 11차만 적용하면 됩니다.**

- AI 상담 속도: **서버(1~2번)** 를 적용해야 바뀝니다.
- 디자인, 기다리는 화면: 사이트 배포로 이미 바뀌었습니다. **Ctrl+F5**로 새로고침하세요.

## 1. Apps Script 코드 바꾸기 (5분)

1. 구글 시트 → **확장 프로그램 → Apps Script**
2. 왼쪽 `Code.gs`를 누르고 내용을 **Ctrl+A → Delete**로 모두 지웁니다.
3. 내 컴퓨터의 `11차_개발\apps-script\Code.gs`를 메모장으로 열어 **전체 복사 → 붙여넣기 → Ctrl+S**
   - 맨 위 주석에 `· 11차`가 보이면 맞습니다.

새 권한이나 새 스크립트 속성은 필요 없습니다(기본값으로 동작).

## 2. 새 버전으로 배포 (1분)

**배포 → 배포 관리 → 연필(편집) → 버전: 새 버전 → 배포**

## 3. AI 답변 속도 확인 (1분)

1. 편집기 위쪽 함수 고르기에서 **`testAiConnection`** → **▶ 실행**
2. 아래 **실행 로그**에서 `"model":"gemini-3.5-flash-lite"`와 `"ms":` 숫자를 봅니다.

| `ms` 값 | 뜻 |
|---|---|
| 1000~8000 (1~8초) | 정상. 다람이 답이 몇 초 안에 옵니다 |
| 20000 이상 | 이 모델도 지금 느림 → 아래 '더 느리면'을 해 보세요 |
| `"result":"quota"` | 이 모델의 무료 한도 초과. 대체 모델이 자동으로 한 번 받습니다 |
| `"result":"model"` | 모델 이름을 못 찾음. 스크립트 속성 `GEMINI_CHAT_MODEL`을 확인 |

사이트 다람이 창 → **자료 정리 → AI 연결 시험**에서도 같은 시간(초)이 보입니다.

**더 느리면** (스크립트 속성: 편집기 왼쪽 톱니바퀴 → 스크립트 속성)

| 속성 | 넣을 값 | 기본값 |
|---|---|---|
| `GEMINI_CHAT_MODEL` | `gemini-3.1-flash-lite` 또는 `gemini-3.6-flash` | `gemini-3.5-flash-lite` |
| `GEMINI_FALLBACK_MODEL` | 다른 모델 이름, 끄려면 `none` | `gemini-3.6-flash` |

값을 바꾼 뒤에는 다시 배포할 필요 없이 바로 적용됩니다. 어느 모델도 느리면 무료 등급이 붐비는 것이라, AI Studio에서 결제를 연결해 유료 등급으로 올리는 것이 확실한 방법입니다.

## 4. 자료 정리 확인 (10차 수정)

편집기에서 **`autoDigest`** → **▶ 실행** 후 다람이 창 **자료 정리**를 엽니다.
- 기대: "정리 끝남 3 · 실패 1 · AI 요약 대기 n". 실패 1은 119 자료집(15.5MB)이고, 7MB 안팎 두세 개로 나눠 넣어야 합니다.
- 권장과목 자료집 정리본이 "구글 변환으로 원문 글자를 뽑음"으로 바뀌었는지 봐 주세요.

## 5. 사이트를 11차로 바꾸기 (완료)

`SITE_DIR`을 `"11차_개발/site"`로 바꿔 배포했습니다(캐시 번호 `?v=17`). 사이트에서 **Ctrl+F5**로 새로고침하세요.

## 6. 적용 뒤 확인할 것

| 확인 | 방법 | 기대 결과 |
|---|---|---|
| 답 속도 | 다람이에게 "9월에 담임이 할 일을 세 가지로 요약해 줘" | 찾은 자료 3개가 바로 보이고, 몇 초 뒤 'AI 답변'으로 바뀜. 아래 시간 줄의 'AI'가 10초 안쪽 |
| 대체 모델 | 답 아래 시간 줄이나 실행 기록 `[다람이 시간]`의 `model`, `firstErr` | 첫 모델이 실패했을 때만 `firstErr`가 채워지고 `model`이 대체 모델 |
| 디자인 | 월별 업무, 연간 흐름, 권장과목, 자료실, 다람이 창(밝은·어두운 화면) | 그라데이션 없이 흰 바탕과 가는 선. 어색한 곳이 있으면 화면을 캡처해 주세요 |
