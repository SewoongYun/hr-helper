# 고3 담임 업무 도우미 · 3차 개발 (검토 반영)

고3 담임 선생님이 **달마다 챙길 업무**를 보고 체크하는 웹사이트입니다.
2027학년도(2028학년도 대입) 기준으로 3월 1차 상담 → 6월 2차 상담 → 8월 하반기 모의평가·최종 상담 → 9월 수시 원서 → 10~11월 면접 → 12월 정시 상담까지 업무 88개와 일정 29개를 넣어 두었습니다.

- **월별 업무**: 이번 달 체크리스트, 이 달의 일정, 기한 D-day, 업무별 자료 링크, 반 메모, 인쇄, 새로고침
- **연간 흐름**: 분류 × 달 흐름표(칸마다 단추), 달별 요약 카드, 일정을 캘린더 파일(.ics)로 받기
- **학년 현황**: 반별·달별 진행률, 업무별 완료 표, 그 달 메모 모아 보기 (학년 코드 필요)
- **내신 9↔5 참고 변환**: 대진대 입학팀 표본 연구의 변환표로 9등급 입결을 5등급 기준으로 가늠(상담 참고용 추정값)
- **권장과목 대조**: 학생 이수 과목과 대학이 밝힌 핵심·권장 과목을 자동 대조할 수 있는 범위만 계산 (지원자격·합격 가능성 판정 아님)
- **자료실**: 대입 사이트와 학교 양식 링크 (교사용 링크는 학년 코드 필요)
- **폼 요약**: 구글폼 응답 건수, 학생 수, 날짜별 인원 (학년 코드 필요, 학생 이름·응답 내용은 오지 않음)

화면 주소 끝의 `#month`, `#conv`, `#subj` 등으로 원하는 화면을 바로 열 수 있습니다.

```

├─ site/                 ← GitHub Pages로 배포되는 폴더
```

## 동작 방식과 저장 위치

```
선생님들 → 사이트(GitHub Pages) ⇄ Apps Script ⇄ 구글 시트 「고3 담임 업무 도우미 (2027학년도)」
```

| 모드 | 업무 내용 | 체크·메모 저장 위치 | 누가 보나 |
|---|---|---|---|
| 오프라인 모드 (`config.js` 비어 있음) | `site/data.js` | 이 브라우저(학교·학년도별 공간) | 이 브라우저를 쓰는 사람 |
| 시트 연결, 학년 코드 없음 | 구글 시트 | 이 브라우저 | 이 브라우저를 쓰는 사람 |
| 시트 연결 + 학년 코드 | 구글 시트 | 구글 시트 `진행` 탭 | **학년 코드를 아는 모든 선생님(모든 반 읽기·수정)** |

| 항목 | 저장 위치 | 공개 범위 |
|---|---|---|
| 업무·일정·월별 요약·권장과목, 자료 이름·설명 | 시트 → 사이트 | **누구나**(사이트 주소를 아는 사람) |
| 자료 링크 중 '교사용' | 시트 | 학년 코드를 넣은 사람 |
| 체크·메모 | 시트 `진행` 탭 또는 이 브라우저 | 학년 코드를 아는 사람 또는 이 브라우저 사용자 |
| 학년 코드 | 시트 `설정` 탭, 이 탭(세션) 또는 '이 기기에 기억하기'를 고른 브라우저 | 설정한 사람 |

- 반 선택은 권한 구분이 아닙니다. 학년 코드를 아는 사람은 모든 반의 기록을 보고 고칠 수 있습니다.
- 공용 PC에서는 '이 기기에 코드 기억하기'를 켜지 마세요. 쓰고 나서 **로그아웃(코드 지우기)**, 필요하면 **이 기기 기록 지우기**를 누릅니다. 로그아웃은 시트 기록을 지우지 않고, 이 기기 기록 지우기는 시트 기록을 지우지 않습니다.
- 2차 버전에서 이 브라우저에 저장한 체크·메모는 처음 열 때 '2027학년도 · 이 기기' 공간으로 복사됩니다(원래 기록은 그대로 둠). 시트에 연결하면 **자동으로 올리지 않고**, 연결 설정 창에서 「시트로 올리기」를 눌러야 올라갑니다. 시트에 이미 같은 반·업무 기록이 있으면 덮어쓰지 않고 보류합니다.

## 1. 구글 시트 연결하기

시트는 만들어 두었습니다. 구글 드라이브에서 **「고3 담임 업무 도우미 (2027학년도)」**를 여세요.

1. `설정` 탭의 **학년 코드** 칸에 코드를 정합니다. **12자 이상 무작위**(예: 비밀번호 생성기)로 정하고 3학년 담임 선생님께만 알립니다. 학기마다, 또 유출이 의심되면 바로 바꿉니다(바꾸면 모두 새 코드를 넣어야 함).
2. 시트 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 기본 코드를 모두 지우고 `apps-script/Code.gs` 내용을 붙여 넣은 뒤 저장합니다. 시간대가 **Asia/Seoul**인지 프로젝트 설정에서 확인합니다.
4. **배포 → 새 배포** → 톱니바퀴에서 **웹 앱**: 실행 계정 **나**, 액세스 권한 **모든 사용자**
5. 권한을 승인합니다. "확인하지 않은 앱" 경고는 본인이 만든 스크립트라 나오는 안내입니다. "모든 스프레드시트 보기·수정" 권한은 폼 요약 기능 때문이며, 코드는 `폼 요약` 탭에 적은 시트만 읽습니다.
6. 표시된 **웹 앱 URL**(끝이 `/exec`) 끝에 `?action=data`를 붙여 열었을 때 `{"ok":true, ...}`가 보이고, 그 안에 학년 코드가 없는지 확인합니다.
7. `site/config.js`에 주소를 넣고 커밋·푸시합니다.
   ```js
   window.HR_CONFIG = { scriptUrl: 'https://script.google.com/macros/s/.../exec' };
   ```

- **학교 Google Workspace 계정에서 '모든 사용자' 배포가 막혀 있으면**, 개인 계정으로 우회하지 말고 학교 정보 담당자에게 승인된 운영 방식(도메인 내 공개, 관리자 허용 등)을 문의하세요. 학교 계정 로그인 기반 인증으로 바꾸는 것이 가장 안전합니다.
- 이미 2차 `Code.gs`를 배포했다면 3차 `Code.gs`를 붙여 넣고 **배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포**를 해야 합니다. 3차 사이트는 3차 `Code.gs`와 함께 써야 합니다(체크 저장 형식이 바뀜).
- **반영 시각**: 시트를 고치면 서버 응답에는 최대 1분 뒤 반영됩니다(메뉴 **담임 도우미 → 사이트 캐시 비우기**를 누르면 바로). 이미 열려 있는 사이트 화면은 자동으로 바뀌지 않으며, 「새로고침」을 누르거나 다른 창에 갔다가 2분 넘게 지나 돌아오면 다시 불러옵니다. 폼 요약은 5분마다 다시 세고, 「지금 다시 세기」를 누르면 바로 셉니다.

## 3. GitHub Pages로 배포하기

상위 폴더(고3 담임 업무 도우미)가 Git 저장소이고, main 브랜치에 올리면 `.github/workflows/deploy-pages.yml`의 `SITE_DIR`(지금 `3차_개발/site`)이 배포됩니다. 배포 전에 index.html이 부르는 파일이 모두 있는지, JavaScript 문법이 맞는지 자동으로 검사하고, 틀리면 배포하지 않습니다.

```bash
git add .
git commit -m "수정 내용 요약"
git push
```

사이트 파일을 고치면 `index.html`의 `?v=4`를 `?v=5`처럼 하나 올려 주세요. 선생님들 브라우저에 예전 파일이 남지 않습니다.

## 4. 폼 요약 설정하기

| 칸 | 예시 | 설명 |
|---|---|---|
| 이름 | 면접 준비 사전조사 | 카드 제목 |
| 반 | 3-7 | 비우면 '공통' |
| 응답 시트 주소 | `https://docs.google.com/spreadsheets/d/…/edit` | 폼 응답이 쌓이는 시트 |
| 탭 이름 | 설문지 응답 시트1 | 비우면 첫 탭 |
| 날짜 열 키워드 | 면접일 | 머리글에 이 글자가 들어간 열을 날짜로 셉니다 |
| 중복 확인 열 키워드 | 학번 | 학생을 구분하는 열. 없으면 학생 수를 세지 않고 응답 건수만 보여 줍니다 |
| 대상 인원 | 24 | 적으면 미제출 수(학생 수 기준)를 보여 줍니다 |

집계 기준:
- **응답(건)**: 첫 칸(타임스탬프)이 있는 모든 행
- **학생(명)**: 중복 확인 열 값이 같은 응답은 한 명. 여러 번 낸 학생은 타임스탬프가 가장 늦은 응답만 씁니다
- **학번 빈 응답**: 학생을 알 수 없는 응답 건수. 학생 수와 날짜별 인원에서 빠집니다
- **날짜별 인원**: 학생별 최근 응답에서 날짜 열들을 모아, 같은 날짜는 한 번만 셉니다. 연도가 없는 날짜는 학년도 기준(3~12월은 그해, 1~2월은 다음 해)으로 붙이고 그 사실을 표시합니다. 없는 날짜(2월 30일 등)는 빼고 개수를 표시합니다

## 5. 내년에 다시 쓰기

1. 시트를 복사합니다(파일 → 사본 만들기). 사본의 `진행` 탭 2행부터 지웁니다.
2. `설정`의 학년도·대입 학년도, 학년 코드를 바꿉니다.
3. 새 「대학입학전형기본사항」을 보고 `일정`·`업무`를 고칩니다.

## 6. 내신 변환과 권장과목

**내신 9↔5 참고 변환**
- 대학이 공개한 9등급 입결이나 학교의 지난 진학 자료를 5등급 기준으로 **대략 가늠**하는 상담 참고 도구입니다. 대학의 공식 환산점수·합격선·합격 가능성이 아닙니다.
- 결과의 상·평균·하는 원 자료의 열 이름을 그대로 쓴 것입니다. 정확한 통계적 정의는 원 자료 연구보고서로 확인하지 못했습니다(검증 대기).
- 5→9 표는 9→5 표의 역함수가 아니라 원 자료에 따로 실린 표입니다.
- 입결 표 붙여넣기: 머리글에 '입결·등급·컷·내신·평균' 등이 있는 열을 고르고, '모집·인원·경쟁률' 열은 제외합니다. 애매하면 자동으로 바꾸지 않으니 「바꿀 열」에서 고르세요. 복사 결과 마지막 줄에 출처가 붙고, `=`·`+`·`-`·`@`로 시작하는 글자 칸은 수식으로 실행되지 않게 앞에 `'`를 붙입니다.

**권장과목 대조**
- **지원자격·합격 가능성·가점 판정이 아닙니다.** 대학이 밝힌 권장 이수 과목과 자동 대조할 수 있는 범위만 계산합니다.
- 카드 표시: '자동 확인한 조건 모두 충족' / '추가 확인 필요'(판정 못 한 조건이 있음) / '핵심·반영 미충족 있음' / '판정 보류 · 원문 확인'(근거 충돌) / '자동 판정 불가' / '지정 과목 없음'
- 판정하지 않는 것: '국어·사회·과학 교과'처럼 교과 영역으로 적힌 조건, '미적분'(Ⅰ·Ⅱ 중 무엇인지 불명확), '수학②' 같은 대학 고유 묶음, 학점 조건(예: 경희대 정시 수학 18학점·과학 20학점 가점 계획은 원문·적용 전형 확인 필요)
- 비고에 적힌 과목 수 조건 중 뜻이 분명한 것은 '자동 판정 조건' 칸에 다시 적었습니다(서울대 '과학 진로 선택 3과목 이상', 고려대 '과학 권장 과목 중 2과목 이상'). `{과학진로선택}`은 과학 진로 선택 8과목 묶음입니다.
- 다른 지역 대학을 추가하려면 시트 연결·학년 코드 입력 후 권장과목 화면 아래 **시트로 보내기**로 '권장과목' 탭을 만들고 줄을 추가합니다.
