# 10차 적용 순서

10차 사이트는 2026-11-12에 GitHub Pages로 배포했습니다(4번 완료). 고친 내용은 거의 모두 서버(Apps Script) 쪽이라 **1~3번은 선생님이 직접 적용해야 효과가 납니다.**

## 1. Apps Script 코드 바꾸기 (5분)

1. 구글 시트 → **확장 프로그램 → Apps Script**
2. 왼쪽 `Code.gs`를 누르고 내용을 **Ctrl+A → Delete**로 모두 지웁니다.
3. 내 컴퓨터의 `10차_개발\apps-script\Code.gs`를 메모장으로 열어 **전체 복사 → 붙여넣기 → Ctrl+S**
   - 맨 위 주석에 `· 10차`가 보이면 맞습니다.

새 권한은 필요 없습니다.

## 2. 새 버전으로 배포 (1분)

**배포 → 배포 관리 → 연필(편집) → 버전: 새 버전 → 배포**

## 3. 다시 정리되는 것 확인

코드를 바꾸면 PDF 4개가 모두 '할 차례'가 됩니다(9차에서 실패하거나 끊긴 것 포함).

1. 편집기에서 **`autoDigest`** → **▶ 실행**. 변환은 파일당 15~30초라 한 번에 끝납니다.
2. 사이트 다람이 창 → **자료 정리**에서 확인합니다.

| 기대 결과 | 뜻 |
|---|---|
| 정리 끝남 3 · 실패 1 · AI 요약 대기 n | 기본사항·대입상담·권장과목은 원문이 저장됨. 요약은 1시간마다 자동으로 붙음 |
| ✗ 2027학년도 대입정보 119 … 구글 변환 실패 … | 예상된 결과. 아래 5번처럼 나눠 넣기 |

- 권장과목 자료집 정리본(드라이브 `자동 정리(다람이)` 폴더)이 "구글 변환으로 원문 글자를 뽑음"으로 바뀌었는지 봐 주세요. 9차에서 끝내 바뀌지 않던 파일입니다.
- `autoDigest` 실행이 6분 가까이 걸리다 "최대 실행 시간 초과"로 끝나면 그 화면을 캡처해 주세요(10차에서는 그래도 횟수가 남아 4번 뒤 멈춥니다).

## 4. 사이트를 10차로 바꾸기 (완료)

`SITE_DIR`을 `"10차_개발/site"`로 바꿔 배포했습니다(캐시 번호 `?v=16`). 사이트에서 **Ctrl+F5**로 새로고침하세요.

## 5. 119 자료집(15.5MB) 나눠 넣기

구글 변환이 큰 PDF를 받지 않습니다. 코드로는 해결되지 않습니다.

1. PDF를 열어 **인쇄 → PDF로 저장**에서 쪽 범위를 나눠 두세 개로 저장합니다(예: 1~150쪽, 151쪽~끝). 각 파일이 7MB 안팎이 되게 합니다.
2. 나눈 파일을 자료 폴더에 넣고 원래 파일은 폴더에서 뺍니다.
3. 다음 자동 정리 뒤 자료 정리 창에서 글자 수를 확인합니다.

## 6. 휴지통 정리 (선택)

9차가 변환을 되풀이하며 만든 `(다람이 임시 변환) …` 문서 20여 개가 드라이브 휴지통에 있습니다. 30일 뒤 저절로 지워지며, 지금 비워도 됩니다.
