# 고3 담임 업무 도우미 · 1차 개발 (보관용)

> 첫 버전을 그대로 보관한 폴더입니다. 배포하지 않습니다. 지금 쓰는 버전은 [2차_개발](../2차_개발/README.md)입니다.

고3 담임 선생님이 **달마다 챙길 업무**를 한눈에 보고 체크하는 웹사이트입니다.
2027학년도(2028학년도 대입) 기준으로 3월 1차 상담 → 6월 2차 상담 → 8월 최종 상담 → 9월 수시 원서 → 10~11월 면접 → 12월 정시 상담까지 88개 업무와 대교협 공식 일정 26개를 넣어 두었습니다.

- **월별 업무**: 이번 달 업무 체크리스트, 이 달의 주요 일정, 기한 D-day, 업무별 자료 링크, 반 메모, 인쇄
- **연간 흐름**: 분류(상담·생기부·수시·면접 …) × 달 흐름표와 달별 요약 카드, 일정을 캘린더 파일(.ics)로 받기
- **학년 현황**: 반별·달별 진행률, 업무별로 어느 반이 마쳤는지 (학년 코드 필요)
- **자료실**: 대입 사이트와 학교 양식 링크 모음
- **폼 요약**: 기초조사·면접 사전조사 구글폼의 응답 수와 날짜별 인원 (학년 코드 필요, 학생 이름은 오지 않음)

빌드 과정이 없어서 `site` 폴더만 올리면 바로 동작합니다.

```
고3 담임 업무 도우미/
├─ site/                 ← 웹에 올리는 폴더
│  ├─ index.html         화면 뼈대
│  ├─ style.css          디자인
│  ├─ app.js             동작(체크, 시트 연동, 화면 그리기)
│  ├─ data.js            기본 업무 데이터 (시트를 연결하지 않았을 때 사용)
│  └─ config.js          Apps Script 주소를 넣는 파일
├─ apps-script/
│  └─ Code.gs            시트 ↔ 사이트 연결 서버 코드 (Apps Script에 붙여 넣기, 웹에 올리지 않음)
├─ .github/workflows/deploy-pages.yml   main 에 올리면 GitHub Pages 자동 배포
└─ README.md
```

## 동작 방식

```
선생님들 → 사이트(GitHub Pages) ⇄ Apps Script ⇄ 구글 시트 「고3 담임 업무 도우미 (2027학년도)」
                                                   ├ 업무·일정·자료·월별 요약: 여기서 고치면 사이트에 반영
                                                   ├ 진행: 사이트에서 체크하면 여기에 쌓임
                                                   └ 폼 요약: 응답 시트 주소를 적으면 응답 수만 집계
```

| 상태 | 업무 내용 | 체크·메모 저장 위치 |
|---|---|---|
| `config.js` 비어 있음 | `site/data.js` | 그 브라우저 |
| 시트 연결, 학년 코드 없음 | 구글 시트 | 그 브라우저 |
| 시트 연결 + 학년 코드 | 구글 시트 | 구글 시트 `진행` 탭 (다른 기기·다른 선생님과 공유) |

오른쪽 위 상태 단추를 누르면 학년 코드를 넣을 수 있습니다. 코드를 넣기 전에 체크한 우리 반 기록은 코드를 넣을 때 시트로 올라갑니다.

## 1. 구글 시트 연결하기 (약 10분)

시트는 이미 만들어 두었습니다. 구글 드라이브에서 **「고3 담임 업무 도우미 (2027학년도)」**를 여세요.

1. `설정` 탭의 **학년 코드** 칸(노란색)에 코드를 정해 적습니다. 3학년 담임 선생님들께만 알려 주세요.
2. 시트 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 기본 코드를 모두 지우고 `apps-script/Code.gs` 내용을 붙여 넣은 뒤 저장합니다.
4. 오른쪽 위 **배포 → 새 배포** → 톱니바퀴에서 **웹 앱**을 고릅니다.
   - 실행 계정: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
5. **배포**를 누르고 권한을 승인합니다. "Google에서 확인하지 않은 앱" 경고가 나오면 **고급 → (프로젝트 이름)으로 이동**을 누릅니다. 본인이 만든 스크립트라서 나오는 안내입니다.
6. 표시된 **웹 앱 URL**(끝이 `/exec`)을 복사합니다. 주소 끝에 `?action=data`를 붙여 브라우저에 넣었을 때 `{"ok":true, ...}`가 보이면 성공입니다.
7. `site/config.js`의 따옴표 안에 붙여 넣고 다시 올립니다(3번 참고).
   ```js
   window.HR_CONFIG = { scriptUrl: 'https://script.google.com/macros/s/.../exec' };
   ```

- 학교 Google Workspace 계정은 "모든 사용자"를 고를 수 없을 수 있습니다. 그때는 개인 Gmail 계정으로 만드세요.
- `Code.gs`를 고친 뒤에는 **배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포**를 해야 반영됩니다. URL은 바뀌지 않습니다.
- 시트를 고치면 1분 안에 사이트에 반영됩니다. 시트 메뉴 **담임 도우미 → 사이트 캐시 비우기**를 누르면 바로 반영됩니다(메뉴는 Apps Script 저장 후 시트를 새로 고치면 생깁니다).

## 2. 시트 고치는 법

| 탭 | 내용 |
|---|---|
| `설정` | 학년도, 학교, 반 목록, 학년 코드 |
| `월별 요약` | 달마다 제목과 핵심 한 줄 (연간 흐름 카드) |
| `업무` | 한 줄이 업무 하나. **월**은 `준비`, `3`~`12`, `1`, `2`, `매월`(모든 달에 반복). **기한**을 넣으면 D-day와 '기한 지남'이 표시됩니다. **중요**를 체크하면 ★. **자료**에는 `자료` 탭의 ID를 쉼표로 넣습니다. |
| `일정` | 날짜가 정해진 일정. **중요**를 체크하면 사이트 위쪽 D-day에 나옵니다. 학사일정(지필평가, 모의고사, 학부모 총회)이 나오면 여기에 추가하세요. |
| `자료` | 링크가 비어 있는 학교 양식은 구글 드라이브에 올린 뒤 주소를 넣으면 업무 카드에서 바로 열립니다. 드라이브 공유 설정을 '링크가 있는 학교 선생님' 이상으로 열어 두어야 다른 선생님도 열 수 있습니다. |
| `진행` | 사이트에서 체크하면 자동으로 쌓입니다. |
| `폼 요약` | 아래 4번 참고 |

업무 **ID는 한 번 정하면 바꾸지 마세요.** 체크 기록이 ID로 연결됩니다. 새 업무는 새 ID(예: `m09-09`)로 추가합니다.

## 3. GitHub Pages로 배포하기

이 폴더는 Git 저장소이고, main 브랜치에 올리면 `site` 폴더가 GitHub Pages로 자동 배포됩니다.

처음 한 번만 설정합니다.

1. GitHub에서 **New repository**로 빈 저장소를 만듭니다. 이름은 `hr-helper`처럼 영문으로, **Public**, README 추가 옵션은 모두 끕니다.
2. 이 폴더에 연결하고 올립니다. 처음 올릴 때 브라우저 로그인 창이 뜹니다.
   ```bash
   git remote add origin https://github.com/SewoongYun/hr-helper.git
   git push -u origin main
   ```
3. 저장소 **Settings → Pages → Source**를 **GitHub Actions**로 바꿉니다.
4. **Actions** 탭에서 실패한 실행을 다시 실행합니다. 끝나면 `https://sewoongyun.github.io/hr-helper/`로 접속합니다.

이후 수정할 때는 세 줄이면 됩니다.

```bash
git add .
git commit -m "수정 내용 요약"
git push
```

업무 내용만 바꿀 때는 Git 없이 **시트만** 고치면 됩니다.

D 드라이브에서 git 명령이 `detected dubious ownership` 오류를 내면 한 번만 아래를 실행합니다.

```bash
git config --global --add safe.directory "D:/수학과/★ 2026 수학과(윤세웅)/클로드로 개발하기/자체 개발 앱/고3 담임 업무 도우미"
```

커밋 작성자 이메일은 공개 저장소에 개인 이메일이 남지 않도록 `SewoongYun@users.noreply.github.com`으로 설정해 두었습니다.

## 4. 폼 요약 설정하기

`폼 요약` 탭에 한 줄씩 적습니다.

| 칸 | 예시 | 설명 |
|---|---|---|
| 이름 | 면접 준비 사전조사 | 카드 제목 |
| 반 | 3-7 | 비우면 '공통' |
| 응답 시트 주소 | `https://docs.google.com/spreadsheets/d/…/edit` | 폼 응답이 쌓이는 시트 |
| 탭 이름 | 설문지 응답 시트1 | 비우면 첫 탭 |
| 날짜 열 키워드 | 면접일 | 머리글에 이 글자가 들어간 열을 모두 날짜로 세어 '날짜별 인원'을 그립니다 |
| 중복 확인 열 키워드 | 학번 | 같은 학생이 두 번 낸 응답을 한 번으로 셉니다 |
| 대상 인원 | 24 | 적으면 미제출 수를 보여 줍니다 |

- Apps Script를 배포한 계정이 그 응답 시트를 열 수 있어야 합니다. 다른 선생님의 폼이면 그 시트를 배포 계정에 '보기 권한'으로 공유받으세요.
- 1번의 처음 배포 때 승인 화면에 "모든 스프레드시트 보기·수정" 권한이 나오는 것은 이 폼 요약 기능 때문입니다. 코드는 `폼 요약` 탭에 적은 시트만 읽습니다.
- 사이트로 가는 것은 응답 수, 중복 제외 수, 날짜별 인원, 마지막 응답 시각뿐입니다.

## 5. 내년에 다시 쓰기

1. 시트를 복사합니다(파일 → 사본 만들기). `진행` 탭의 2행부터 지웁니다.
2. `설정`의 학년도를 2028, 대입 학년도를 2029로 바꿉니다.
3. 새 「대학입학전형기본사항」(대교협)을 보고 `일정` 탭 날짜와 `업무` 탭의 기한·시기를 고칩니다.
4. 사본 시트에서 1번 절차로 Apps Script를 새로 배포하고 `config.js` 주소를 바꿉니다.

## 개인정보 원칙

- 사이트와 이 저장소에는 학생 정보가 없습니다. 학생 상담 기록, 생기부, 연락처는 지금처럼 구글 시트·폼과 학교 PC에만 둡니다.
- 메모 칸에 학생 이름을 적지 마세요. 메모는 학년 코드를 아는 선생님 모두가 볼 수 있습니다. "미제출 3명"처럼 적습니다.
- 학년 코드는 시트 `설정` 탭에만 적습니다. 저장소나 `config.js`에 넣지 마세요. 웹 앱 주소(`/exec`)는 공개되어도 괜찮습니다. 코드 없이는 업무표 읽기만 됩니다.
- 무료 GitHub Pages는 공개 저장소입니다. 올린 파일은 누구나 볼 수 있고, 한 번 올린 파일은 지워도 이력에 남습니다.
